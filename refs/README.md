# 레퍼런스 이미지 넣는 법

이 폴더의 이미지는 비평가가 빌드 화면과 섞어 놓고 비교하는 기준입니다. 없어도 작업은 진행되지만, 있을 때 평가가 구체적입니다.

- 6~10장을 넣습니다. PNG나 JPG, 가로 1280픽셀 이상이면 됩니다.
- 장면을 섞습니다. 밝은 실외, 어두운 실내, 실내에서 창을 바라볼 때, 사격 순간, 달리는 중.
- 자막, 채널 로고, 재생 화면의 버튼이 없는 프레임을 고릅니다. 이런 요소가 있으면 비평가가 화면 품질이 아니라 그것으로 구분하게 됩니다.
- 전체 화면으로 재생한 상태에서 캡처합니다.
- 파일 이름은 자유입니다. 비교 시트를 만들 때 이름은 가려집니다.

이미지는 화질과 카메라 느낌의 비교 기준으로만 씁니다. 게임에 넣거나 저장소에 올리지 않습니다. `.gitignore`가 이 폴더의 이미지를 커밋에서 제외합니다.
