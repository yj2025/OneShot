직접 플레이한 뒤에 쓰는 지시문입니다. 먼저 PLAYTEST.md에 기록을 적고 아래 블록을 보냅니다.

```
직접 플레이하고 PLAYTEST.md에 기록을 추가했어. 읽고 이렇게 처리해 줘.

- 동작이 틀린 것은 지금 고쳐. 고치기 전에 그 문제를 재현하는 검사를 만들고, 고친 뒤 npm run check를 돌려.
- 화면이나 느낌에 관한 지적은 지금 고치지 말고 BACKLOG.md의 해당 종류에 넣어. 맞는 종류가 없으면 새로 만들어.
- 끝나면 무엇을 고쳤고 무엇을 BACKLOG.md의 어디에 넣었는지 알려 줘.
```

화면에 관한 지적을 바로 고치지 않는 이유는, 지적 하나에 수정 하나로 대응하면 같은 지적이 되풀이되기 때문입니다. 그 지적은 해당 작업 묶음을 맡는 세션에서 한꺼번에 다룹니다.
