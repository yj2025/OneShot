# 지시문 목록

Claude Code에 붙여 넣는 지시문입니다. 세션은 항상 레포 루트에서 시작합니다.

| 파일 | 언제 쓰나 |
| --- | --- |
| `10-phase0.md` | ROADMAP.md 0단계. 한 번 보냅니다. 옆에서 결과를 봅니다 |
| `11-session.md` | 1~4단계. 세션마다 작업 묶음 하나를 넣어 보냅니다 |
| `goal.md` | `11-session.md`를 보낸 뒤 자리를 비울 때 입력하는 `/goal` 한 줄 |
| `02-resume.md` | 세션이 중단돼서 새 세션으로 이어 갈 때 |
| `03-feedback.md` | 직접 플레이하고 PLAYTEST.md에 기록을 적은 뒤 |
| `01-kickoff.md` | 첫 빌드를 만들 때 쓴 지시문. 끝났으므로 다시 쓰지 않습니다 |

한 단계는 이렇게 돕니다.

1. ROADMAP.md에서 지금 단계의 작업 묶음 하나를 고릅니다.
2. `11-session.md`의 대괄호를 채워 보내고, 자리를 비울 거면 `goal.md`의 한 줄을 입력합니다.
3. 세션이 끝나면 docs/shots/의 전후 시트를 보고 직접 플레이합니다. 거슬리는 점은 PLAYTEST.md에 적고 `03-feedback.md`를 보냅니다.
4. 묶음을 다 돌았고 ROADMAP.md의 통과 기준을 넘었다고 판단하면 ROADMAP.md의 진행 상태 표를 고칩니다.
