자리를 비울 때 01-kickoff.md를 보낸 다음에 입력하는 한 줄입니다. 아래 줄만 복사해서 그대로 입력합니다. SPEC.md의 시간 상한을 바꿨다면 6시간 부분도 같이 고칩니다.

```
/goal 다음이 모두 대화에 증거로 나와 있다. 첫째, npm run check 실행 출력이 종료 코드 0으로 끝났다. 둘째, CRITIC_LOG.md의 마지막 두 라운드 판정이 모두 '큰 격차 없음'이거나, PROGRESS.md 첫 줄의 시작 시각과 date 명령 출력으로 6시간 경과가 확인됐다. 셋째, SPEC.md 형식의 마지막 보고가 출력됐다. 진행 중에 SPEC.md와 .claude/ 아래 파일은 수정하지 않는다.
```

이 조건은 턴이 끝날 때마다 별도 모델이 대화 내용만 보고 확인합니다. 그래서 조건을 명령 출력처럼 대화에 드러나는 증거로 적었습니다. 걸어 둔 goal은 `/goal clear`로 지웁니다.
