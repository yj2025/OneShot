## 4. 남은 문제 (BACKLOG.md에 종류별로 있음)
1. **(l) 가까운 바닥**: 형광등 거의 바로 아래에서 바닥을 내려다보는 시점(뷰 10)이다. 총은 등에서 약 1.3 m, 바닥은 2.55 m라 받는 빛이 약 3배이고, 총이 둘레의 0.55배가 된다. 반사율이나 반사 모양으로는 더 줄일 수 없다. 형광등을 관 전체의 조도로 받으면 오히려 0.61로 오른다. 기준을 그대로 둘지는 사용자가 정한다. 검사를 느슨하게 하지 않았다.
2. **A/B 70%**: 기준선이 이긴 쌍이 없어도 '구분 안 됨'이 22~25쌍이라 61%에 머문다. 세 번 제자리(60 → 56 → 61%)의 원인 분석은 PROGRESS.md '제자리 세 번의 원인'에 있다. 바깥 6쌍은 일부러 그대로 두었다. 시트 크기에서 총은 화면의 5~10%다.
3. **모든 판정자의 공통 격차(묶음 밖)**: 소매가 주름, 솔기, 소맷부리 없는 원통이고 장갑이 손가락 없는 덩어리다. 총 표면에 긁힘과 도장 마모가 없다. 걷는 동안 총이 화면에 붙어 있다. → 2단계 ③ '손과 총 디테일'.
4. **바깥 재질의 반사율**: 아스팔트 8.7%, 자갈 9.9%로 실제의 절반쯤이고 반사율 표에 없다. 그래서 반사 프로브를 건물 밖에서 끄고 있다. critic 35 판정 1은 '조준경 렌즈가 하늘을 비추지 않는 검은 원판'이라고 적었다.
5. **문 칠 색(청회색)**: 판정이 갈렸다. '벽과 같은 빛을 받은 칠면'이 2쌍, '명암 없이 고르게 밝은 판'이 3쌍이다.
6. **화염 순간의 장갑**: A/B 51 판정 2명이 한쪽 장갑이 고르게 겨자색이라고 적었다(어느 빌드인지는 모른다). 잰 화염 배율은 장갑 1.81, 총 1.27이다.
7. **검사의 흔들림**: '걷기와 달리기 구분'이 다른 3D 게임이 GPU를 쓰는 동안 한 번 실패했다(2.68/2.68 m/s). 따로 돌리면 통과한다. 실시간 검사라 부하를 탄다.

## 7. 이 폴더

  - `look.mjs "2,3,4,6,7,10"`: 시점별 뷰모델 밝기 ÷ 둘레 밝기(전체, 총, 장갑, 소매)와 소매의 채널별 반사율. 검사 (l)의 값을 따로 볼 때 쓴다. 두 번째 인자로 재질을 덮어쓸 수 있다(`'{"only":"sleeve","sheen":0}'`).
