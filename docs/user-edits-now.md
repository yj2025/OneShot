## 4. .claude/settings.json: 판정자에게 git 상태를 보이지 않게

판정자(서브에이전트)에게 git 상태 요약(최근 커밋 제목, 고친 파일 이름)이 자동으로 붙는다. 서브에이전트별로 끄는 방법은 없고, 프로젝트 전체에서 끈다. 공식 문서(code.claude.com/docs/en/env-vars)의 `CLAUDE_CODE_DISABLE_GIT_INSTRUCTIONS`를 쓴다. 이 값은 커밋과 PR 안내문과 git 상태 요약을 함께 뺀다. 작업하는 Claude는 git 명령을 직접 돌리므로 일에 지장이 없다.

`"permissions": {` 바로 위에 한 덩어리를 넣는다.
```
  "env": {
    "CLAUDE_CODE_DISABLE_GIT_INSTRUCTIONS": "1"
  },
```
넣은 뒤의 앞부분
```
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "env": {
    "CLAUDE_CODE_DISABLE_GIT_INSTRUCTIONS": "1"
  },
  "permissions": {
```
설정은 세션을 시작할 때 읽힌다. 고친 뒤 새 세션을 열고, 첫 평가 전에 판정자의 맥락에 git 상태가 없는지 한 번 확인한다(PROGRESS.md에 적는다).
