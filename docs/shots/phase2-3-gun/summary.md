# 2단계 ③ 손과 총 디테일: 전후 시트와 측정값

2026-11-14. 기준선은 세션을 시작할 때의 빌드(커밋 224906c의 게임, 'p2-gun'), 새 빌드는 끝 평가를 받은 빌드다(이 폴더와 함께 커밋된 빌드와 같다). 레퍼런스가 들어간 이미지는 없다. ROADMAP의 순서로는 뒤에 있지만 사용자가 이 묶음을 먼저 하기로 정했다.

## 파일
- `before-after-1.jpg` ~ `5.jpg`: 정지 화면 15장(가까운 장면 4장 포함). 왼쪽이 기준선, 오른쪽이 새 빌드다.
- `before-after-6.jpg` ~ `9.jpg`: 연속 프레임 4묶음(1초 8장). 위가 기준선, 아래가 새 빌드다.

## 무엇이 달라졌나
- 왼손이 핸드가드 밑을 받치고 손가락이 옆을 감아 올라간다. 왼팔은 화면 왼쪽 아래에서 비스듬히 들어온다.
- 총의 자세가 장면마다 다르다(몇 초 단위로 떠도는 높이, 좌우, 기울기). 돌 때 더 크게 뒤처지고, 걸음마다 총끝이 끄덕이고 좌우로 돈다. 탄은 총이 향하는 방향으로 나가므로 이 움직임이 탄착에도 들어간다(조준할수록 줄어든다).
- 총, 장갑, 소매의 반사를 줄였다(머리 위 형광등 밑에서 하얗게 번들거리지 않는다). 부품마다 색은 그대로다.
- 렌즈 앞 0.7 m 안은 초점이 나간다. 깊이가 비슷한 것끼리만 섞어 가까운 밝은 벽이 총 위로 번지지 않는다.
- 평가: A/B에 가까운 장면 4개를 더했다(쌍 15개 → 19개, 사용자 결정). 영점 확인에서 19쌍 모두 '구분 안 됨'이었다.
