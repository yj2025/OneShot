# A/B 판정 원문과 쌍별 결과

`npm run ab -- score`가 채점할 때마다 `ab-round-N.json`을 여기에 쓴다. out/은 커밋되지 않아서, 여기에 남기지 않으면 나중에 다시 셀 수 없다(측정 정비 2차, docs/evaluation.md).

- `judgments`: 판정자마다 받은 답 한 줄(원문). 좌우 교차 라운드는 `set`에 그 판정자가 본 벌 이름이 있다.
- `summary`: 승(W), 패(L), 구분 안 됨(T), 부호 검정 p, 판정, 글자 집계, 자리 집계, 방향이 갈린 쌍, 옛 방식 비율.
- `pairs`: 쌍(장면)마다 결과(`W` 새 빌드 승, `L` 기준선 승, `T` 구분 안 됨), 새 빌드 표, 기준선 표, 구분 안 됨, 벌마다의 번호와 새 빌드가 놓인 글자.
- 채점이 끝난 라운드의 쌍별 결과라 정답이 들어 있다. 판정자에게 이 폴더의 경로를 넘기지 않는다. 시트는 라운드마다 새로 섞으므로 지난 정답이 다음 라운드의 답을 알려 주지는 않는다.
